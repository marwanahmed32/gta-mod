# Turbo Cars Mod — UI prototype

واجهة أولية لمشروع قائمة عربيات GTA V، تستهدف تجربة استخدام على شاشة PS4.

## السيارات في القائمة
- Lamborghini Aventador
- Bugatti Chiron
- Ferrari SF90
- Nissan Skyline R34
- Toyota Supra MK4

## تشغيل محلي
افتح `index.html` في متصفح حديث.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا باسم `turbo-cars-mod`.
2. ارفع الملفات الأربعة: `index.html`, `style.css`, `app.js`, `cars.js`.
3. من Settings → Pages اختر النشر من الفرع الرئيسي (`main`) ومجلد الجذر (`/root`).

## حدود النسخة الحالية
هذه واجهة ويب فقط: تعرض قائمة السيارات وتسمح باختيارها، لكنها لا تحقن كودًا في GTA V ولا تستدعي مركبة داخل اللعبة. يلزم تطوير واختبار مكوّن منفصل داخل اللعبة متوافق مع نسخة اللعبة وبيئة الجهاز قبل تنفيذ وظائف الاستدعاء وتعديل السرعة. بيانات `speed` و`accel` هنا تصنيفات واجهة وليست إعدادات فعلية للعبة.
